# Reproducibility and release procedure {#sec:reproducibility}

The repository records the exact runtime dependency graph in `uv.lock` and
uses `uv sync --locked --extra dev` for development. The release procedure is:

```bash
uv sync --locked --extra dev
uv run ruff check blockference tests GRTs scripts
uv run pytest -q
uv run python scripts/execute_notebooks.py
uv run python scripts/validate_manuscript.py
uv run python scripts/build_manuscript.py
uv run python scripts/build_manuscript.py --check
uv run blockference pipeline --config configs/smoke.yml --output-root /tmp/activeblockference --run-name smoke
```

The last command emits a run tree whose `validation_report.json` is the single
artefact-level release verdict. The output root is intentionally outside the
repository in this example, so generated runs do not become source files.

## Provenance of the figures

Figures 1, 2, and 3 are structural diagrams generated by the manuscript
builder. Figure 4 is computed from a seeded `run_experiment` call with the
configuration recorded in [@tbl:reference-run]. The figure generator imports
the public package API, uses the same action vocabulary and simulation
semantics as the release pipeline, and checks the generated figures in the
manuscript validation step.

## Software citation

The code artifact is released as ActiveBlockference 1.0.0 under the MIT
license. The repository itself is citable using [@ActiveBlockference2026].
The release makes a deliberate compatibility boundary: callers should use the
typed `blockference` CLI, `GridWorld`, `plot_efe`, `PipelineResult.ok`, and the
strict configuration and validation helpers documented in [@sec:implementation]
and [@sec:validation].
