# AGENTS.md — `docs/tutorials/`

Same rules as `docs/AGENTS.md`, plus:

* Each tutorial is a **runnable** end-to-end story. Code in fences must
  execute against the current `blockference` API.
* If a tutorial breaks because of a library change, update the tutorial
  in the same PR as the change.
* Keep them short — 60–120 lines of Markdown is the sweet spot.
