# Gridworld notebooks

The notebooks demonstrate `ActiveGridference`, `GridWorld`, deterministic
multi-agent movement, and current coordinate conventions. They can be executed
independently from the repository root.

* `agent_api_single.ipynb` — one generative model.
* `gridference_single.ipynb` — one inference step.
* `modular_single.ipynb` — repeated environment steps.
* `multiple_agents_network.ipynb` — keyed multi-agent state.
* `two_multi_agent.ipynb` — competing target resolution.
* `gridworld_walkthrough.ipynb` — configuration plus movement.
* `multi_agent_grid.ipynb` — multi-agent movement.
* `dict_multi_agent.ipynb` — dictionary action input.
