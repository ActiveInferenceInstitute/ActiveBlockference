# `notebooks/ants/` — collective-behaviour exploration

`blockferants.ipynb` extends ActiveBlockference toward swarm-style
foraging dynamics: many small Active Inference agents whose preferences
include neighbour-relative observations.

This is **early-stage**: the notebook is a sandbox for ideas about how
local AIF agents can give rise to colony-level patterns (trail formation,
food retrieval, collision avoidance).

## Status

Experimental. Expect to refactor logic into `blockference/envs/` once the
abstractions stabilise.
